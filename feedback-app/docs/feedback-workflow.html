3 / Inside automatic RCA

How RCA checks the expected answer

Neo4j finds the documents. Sonnet 4.6, through the L’Oréal gateway, checks the supported facts and diagnoses the gap.

Where does the expected answer come from?Neo4j stores document passages, not ready-made expected answers. Sonnet uses those passages to identify what a good answer should contain. A user’s expected-answer hint is checked against the documents, not accepted as truth.

—

Rendering how RCA works…

Not enough evidence? Return “insufficient evidence” / “inconclusive”, keep any saved answer and ask for review. Do not invent an expected answer or treat a suggested cause as proven.

On retest: assess the new answer and compare it with the captured baseline using document evidence. Usable passages returned by NEO can be reused; otherwise the app searches Neo4j. This does not change NEO’s own retrieval.

    accTitle: How Neo4j and Sonnet support root-cause analysis
    accDescr: The question and expected-answer hint guide semantic and keyword search in Neo4j. Relevant document passages, context and source references are retrieved. Sonnet uses those documents to identify expected facts and compare them with the NEO answer and user feedback. It suggests a root cause, missing or wrong facts and an explanation with citations. These are unverified suggestions, not a certified expected answer or proof of what NEO originally retrieved.

    Q["Question + expected-answer hint"]:::input
    Q --> SEARCH["Search Neo4j documents<br/>semantic + keyword search"]:::evidence
    SEARCH --> DOCS["Retrieve relevant passages<br/>nearby context + source references"]:::evidence
    DOCS --> JUDGE["Sonnet identifies expected facts<br/>from the documents and compares<br/>them with NEO’s answer"]:::ai
    ANSWER["NEO answer + user feedback"]:::input --> JUDGE
    JUDGE --> RCA["Suggested RCA: likely cause<br/>missing / wrong facts<br/>explanation + citations"]:::ai

Reporter

Submit or correct permitted details on your own feedback, follow status, read saved answers and safe RCA, and confirm fixed or explain what is still wrong.

Reviewer

Inspect source evidence, verify expected behavior and the proposed cause, and request retests. Private notes, raw evidence and tool traces stay reviewer-only.

AI cannot close a report. Resolution needs the actual owner’s explicit response to the latest completed saved result for the current revision and the same known environment. A non-production result cannot resolve a production report.
