Worker. Enabled by default, polling about every 15 s. Jobs are claimed under a lease (renewed while running) with idempotency keys on enqueue, so only one worker instance processes a job and retries stay safe. Agent calls are restricted to an allow-listed host.

    accTitle: Low level backend modules of the Agent Quality Console
    accDescr: The HTTP surface has auth routes, reporter routes under /api/my, reviewer routes for feedback and overview, workflow actions for analysis retests and answer RCA, golden dataset and evaluation routes, plus environment, access and role demo routers. Behind them sit the workflow repository and worker, the root cause gateway client, Neo4j evidence retrieval, agent targets with endpoint tests, ownership and submission helpers, the auth module, access and environment repositories, and dashboard, evaluation and demo helpers. External systems are BigQuery, Neo4j, the AI gateway and the NEO agent API.
